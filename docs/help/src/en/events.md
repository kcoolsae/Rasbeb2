#### Events
To be able to take part in a contest with your class, you have to set up one or more *events*
for it. Pupils then take part in one of these events. You can
set up several events for the same contest.

You find your school's events on the *Home* page. (First option in the menu at the top.)

An event has a number of settings
* The *contest* the event belongs to
* The *age group* of the pupils who can take part in this event.
Belgium has four different age groups, one for each stage of
secondary education, and one for the 5th/6th year of primary education.
(See also [concepts](overview.html#age-groups).)
* The *language* used for the contest questions. In your school you can offer
the same contest in different languages[^1].
* A *title* that you choose yourself (e.g. *Friday 5b English*) to help you
tell the different events apart. Pupils also see the titles
of the events for which they are subscribed[^2].

Creating an event is not enough, however!
* You have to *subscribe* the pupils to a specific event
* You have to *open* the event so that the pupils can take part

#### Subscribing pupils to an event
Pupils cannot simply take part in an event. They first have to be given permission - be *subscribed*
to that event. You can only subscribe pupils who have already been
registered with the system. (See [registration](registration.md) - but you can also register a single pupil on the subscription page.)

You subscribe pupils on the event's detail page. Subscribing is done there *class by class*: for each class, tick in 
the right-hand column the pupils
who may take part in the event and then press the 'Update' button at the top of that same class to save your changes.
(You can also tick or untick a whole class at once with the checkbox in the column header.)
 
#### Opening and closing
To start an event, you have to *open* it so that pupils can take part in it. An event for the official contest can only be opened
once the contest itself has been opened.

When the event is over, you have to *close* it. For a restricted (school) contest, pupils can see their results and the solutions and additional feedback
as soon as the event is closed. For the official contest, this is only possible after the contest itself has been closed as well.

While an event is open, you can see on the event's detail page which pupils are taking part and how much time they have left. 
In case of problems you can grant a pupil additional time, or readmit a pupil who has accidentally ended their participation.

#### Deleting
An event can be deleted, for example when you created it with the wrong age group, as long as
no pupils have taken part in that event yet. Subscriptions to that event are then lost. So do not forget to
subscribe those pupils to another event.

#### Footnotes

[^1]: Most contests are offered in Dutch and French, and more recently in English as well.

[^2]: 
    If you organize a test contest (based on an earlier Bebras Challenge) before taking part in
    the 'real' contest, make sure that the title of the corresponding events reflects this
    so that a pupil does not accidentally take part in the wrong event. 
    (If you have closed the test event properly, this cannot happen.)
