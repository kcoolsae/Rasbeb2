Taking part in a contest
===

{% include _menu_en.md %}

---
A pupil has to log in (via the contest URL) to be able to take part in a
contest (event)[^1]. Logging in is done with a numeric Bebras ID and
a password. The ID and password are created by the system
when the teacher [registers](registration.md) the pupil.

A pupil's home page contains a list of
* All events in which they have already taken part during the year[^2].
* All other events for which they have been given permission.

It is best to make sure that this last list contains only one event
that is open. It has happened in the past that a pupil took part in a test event
instead of the official contest.
(During the event the teacher can get an overview of who is
taking part at that moment.)

For an event in which pupils have previously taken part, they can see their results (score), the correct answers
and the explanations of the answers. (For the official contest, however, this is only possible after the end of the official Bebras weeks.)
For an event that is open and in which they have not yet taken part, there is a link
with which they can start their participation.

#### Footnotes

[^1]: To try out a public contest anonymously, you need not (and may not) log in. Take care that pupils do not accidentally take part anonymously in the wrong contest - this has happened in the past.

[^2]: Or to be completely correct: all contests for that Bebras ID. But in principle pupils get a new ID every year.
