### Contests / events

The web application supports three kinds of **contests**
* The _official_ Bebras Challenge, in November. You can only take part in this contest 
during the two Bebras weeks.
* *Restricted* contests (or *school contests*) - a selection of earlier Bebras Challenges that you can organize in your class
  as you please.
* A *public* contest[^3] in which you can only take part anonymously. It serves as a first introduction
  to Bebras.

Each contest consists of a number of questions/tasks. You only get a
limited time to solve them. The questions exist in both Dutch and French, and
for the more recent contests, in English as well.

To take part in a contest with a class (official or restricted),
the teacher must create an **event** for it and subscribe pupils
to that event. When the event is opened later, those
pupils can take part in it. Only after you have closed the event
can they see their result (score) and the correct answers (with explanations).

### Age groups
Which questions you get depends on the chosen age group. In Belgium there
are four age groups, named after characters from the Star Wars films:

* **Ewok** 5th/6th year of primary education
* **Wookie** Stage 1 of secondary education (1st/2nd year)
* **Padawan** Stage 2 of secondary education (3rd/4th year)
* **Jedi** Stage 3 of secondary education (5th/6th year)

When creating an event, the teacher specifies which age group
the event is for (and for which language).

### Classes / schools / school years
The web application groups teachers by school - in other words, teachers from the
same school can see and modify each other's events, classes, etc.

Events and classes are grouped by school year, and therefore have to be
created anew each school year.

Pupils, too, have to be registered with the server anew every year, assigned to a
class and subscribed to specific events.

Teachers also have (read) access to data from earlier school years.

### Users / logging in
The web application distinguishes between _pupils_ and _teachers_[^2]. They also
use separate URLs to log in.

Pupils
* can only take part in a contest (event), see their results, the
correct answers and the accompanying explanations
* are registered with the server by their teacher and thus receive a
  user number (Bebras ID) and a password

Teachers
* manage events, classes, pupils, … for their school. They can _not_ take part in a contest
* have to contact the Bebras coordinator for Belgium to get access to
  the server,
* or can receive an account from an already registered colleague *from the same school*

#### Footnotes

[^2]: A third role - administrator - is reserved for the Bebras coordinators for Belgium.

[^3]: Not yet available in English.
