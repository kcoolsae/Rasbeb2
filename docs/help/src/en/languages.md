Language support
===
{% include _menu_en.md %}

---

The application supports several languages. Not only do we support Dutch-speaking, French-speaking
and English-speaking schools, but also schools with pupils from different language groups. A Dutch-speaking
school can, for example, give (a few) pupils permission to take a contest
in French.

The choice of language is used in two different contexts
* The _user interface_ - page titles, button labels, …
* The _contest questions_ - question titles, the questions themselves, the answers, the contest title, …
  
(A number of items are not translated, such as the name of a school or of a class)

Users can choose the language of the interface themselves - the first time
the web application is opened in the browser, but afterwards, too, there is
a menu option to change the language (top right, next to the user's name).

It is, however, the *teacher* who determines the language of the *contest* when creating an
event for it. It is possible to create two events for
the same contest in different languages and to subscribe pupils to the event in the correct language - or even to both,
although we rather advise against the latter.

#### Remark

The questions of a Dutch and a French contest are in principle the same.
Questions that are about 'words', however, are not identical and may therefore
also differ (slightly) in difficulty.
