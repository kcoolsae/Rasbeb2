Après le challenge
===
{% include _menu_fr.md %}

Dès que le challenge officiel est terminé, les points et les réponses sont disponibles. Les élèves peuvent
consulter leurs résultats lorsqu'ils se connectent, et les enseignants peuvent consulter et télécharger une
liste récapitulative :

* Sous *Accueil* (Évènements) → *Détails*, vous voyez les résultats de cet évènement
* Sous *Challenges* → *...* (bouton) → *Participations* (menu), vous voyez les résultats par classe, pour tous les évènements confondus

Dans les deux cas, vous pouvez aussi télécharger les résultats sous forme de fichier Excel.

Sous *Challenges* → *...* (bouton) → *Questions* (menu), vous voyez désormais aussi, pour chaque question, la réponse correcte et la manière
d'arriver à cette réponse. Il y a également (presque)
toujours un petit mot d'explication sur le lien entre la tâche et
l'informatique (et parfois la pensée computationnelle).

(Ce serait bien qu'en tant qu'enseignant, vous trouviez un jour le temps de passer ces réponses en revue
avec vos élèves et de vous arrêter ici et là
sur les aspects informatiques de la question.)

#### Masquer les fausses participations

Nous vous demandons de *masquer*, dans les deux semaines qui suivent la fin du challenge officiel, les participations dites « fausses »,
afin de ne pas « fausser » les statistiques. Une participation peut être « fausse », par exemple parce que
- vous avez vous-même participé pour tester le challenge,
- un élève a fait le challenge seul à la maison, et vous soupçonnez qu'il a été aidé,
- un élève a participé à un moment où ce n'était pas prévu, parce que l'évènement était déjà/encore ouvert,
- …

Pour *masquer* des participations, rendez-vous à l'écran *Challenges*, cliquez sur le bouton « ... » à côté du challenge officiel
de cette année et choisissez *Participations* dans le sous-menu situé sous le titre du challenge. Vous voyez une liste de tous les
élèves qui ont participé au challenge, par classe. Cliquez sur le bouton à l'œil barré pour masquer la participation
de cet élève. 

#### Autres manières de nettoyer les données 
Vous pouvez modifier le nom d'un élève, à cause de fautes d'orthographe, ou parce que vous avez utilisé le compte d'un autre élève
pour un élève.

- Vous pouvez le faire dans l'aperçu des élèves (option de menu *Élèves*), en cliquant sur le crayon à droite du
  nom de l'élève.
- Notez d'ailleurs que, pour un évènement ouvert, vous pouvez encore ajouter rapidement un nouvel élève, qui peut alors participer à l'évènement
  immédiatement. (Sur la page de détail de l'évènement, cliquez sur *Modifier les autorisations*, 
  puis sur *Inscrire un nouvel élève*.)

Vous pouvez supprimer un évènement que vous n'avez pas utilisé - tant que personne n'y a participé. (Cela supprime bien sûr aussi
toutes les inscriptions à cet évènement.)
- Un bouton rouge *Supprimer l'évènement* se trouve en haut de la page de détail d'un évènement.
