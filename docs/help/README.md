# Rasbeb 2 user documentation

This directory contains the user documentation for Rasbeb 2. 

* The `src/` map contains the markdown and CSS files that can be used to generate a corresponding
  website. Run `jekyll serve` from the `src`-folder and then point
  your browser at `http://localhost:4000/nl/index.html/`.
* Documentation is available in Dutch (`src/nl`), English (`src/en`) and French (`src/fr`). The English and French pages are
  translations of the Dutch ones (point your browser at `http://localhost:4000/en/index.html` or `http://localhost:4000/fr/index.html`).
  When you change a Dutch page, please update its English and French counterparts as well.
